# Beauty Bazaar

Static bilingual brand showcase for household essentials and women's everyday accessories.

## Open

Open `index.html` directly, or serve this directory with any static HTTP server.
No build step, package installation, external font or backend is required.

## Contents

- `index.html`: brand homepage and category filters
- `product1.html` to `product6.html`: individual product pages
- `product-data.js`: English/Chinese collection names, descriptions and design information
- `site.js`: language preference, filtering, local favorites and text-file download
- `style.css`: desktop/mobile layouts and reduced-motion support
- `assets/`: original AI-generated brand logo and optimized website images
- `image-prompts.md`: image-generation specifications (local delivery document)

## Publication

GitHub Pages serves the `main` branch at repository root. All asset references are relative.

## Content Boundaries

Products and imagery are illustrative design concepts, not verified manufacturing specifications.
No prices, certifications, reviews, supplier claims, addresses or customer-service contacts are invented.
There is no checkout, ordering system or live inventory. Favorites are stored locally in the visitor's browser.
Publish confirmed product information and real sales/contact channels before using the site as a sales channel.

## Edit

Update product entries in `product-data.js`. Keep both language versions consistent.
Replace images under `assets/` with the same filenames when approved real product photography is available.
Never store credentials or customer data in this public repository.
